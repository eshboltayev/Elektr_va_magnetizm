Kondensator energiyasi. Zaryadlar sistemasi energiyasi. Elektr maydon energiyasi

1Maşğulot maqsadi

Zaryadlangan ötkazgiç, kondensator va zaryadlar sistemasi energiyasini, maydon energiyasi ziçligini hisoblaş; kondensator zaryadlanişida energiya balansini tahlil qiliş.

Nazariy asos: 6-ma’ruza. Ta’lim natijalari: TN3, TN4, TN9.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

\(W=\frac{CU^2}{2}=\frac{q^2}{2C}=\frac{qU}{2}\); \(w=\frac{\varepsilon_0\varepsilon E^2}{2}\). Zaryadlangan sfera maydoni energiyasi \(W=\frac{Q^2}{8\pi\varepsilon_0R}\). RC zanjirda zaryadlaniş: \(q=CU_0(1-e^{-t/RC})\); manba bergan energiya \(CU_0^2\) — yarmi kondensatorda, yarmi rezistorda issiqlikka aylanadi (R ga boğliq emas).

3Işlangan masalalar

1-masala. Kondensator energiyasi

Şart. 10 mkF kondensator 200 V gaça zaryadlangan. Energiya?

Yeçim

\(W=CU^2/2=0{,}2\) J.

2-masala. Kondensatorlarni ulaş

Şart. Zaryadlangan \(C\) kondensator (\(U_0\)) xuddi şunday zaryadsiz kondensatorga parallel ulandi. Energiya qanday özgaradi?

Yeçim

Zaryad teng bölinadi: \(U=U_0/2\); \(W'=2\cdot C(U_0/2)^2/2=W_0/2\). Yarmi ötkazgiçlarda issiqlik va nurlanişga ketadi.

3-masala. Sfera maydoni energiyasi

Şart. \(R=10\) sm sferada 10 nC zaryad. Maydon energiyasi?

Yeçim

\(W=Q^2/(8\pi\varepsilon_0R)=kQ^2/2R=4{,}49\) mkJ.

5Interaktiv model: RC zanjir: zaryadlaniş va energiya

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu model kondensatorning zaryadlanişini körsatadi. Vaqt doimiysi nol butun bir sekund.
  2. Öng grafikka qarang: manba bergan energiyaning aniq yarmi kondensatorda töplanadi, yarmi rezistorda issiqlikka aylanadi.
  3. Qarşilikni beş marta oşiramiz: zaryadlaniş sekinlaşdi, lekin energiyalar nisbati baribir yarmiga teng.
  4. Razryad: kondensator energiyasi töliq rezistorda issiqlikka aylanadi.
  5. Namoyiş tugadi.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN4, TN9).

import numpy as np
R, C, U0 = 1e3, 100e-6, 10.0
t = np.linspace(0, 10*R*C, 100001); dt = t[1] - t[0]
I = U0/R*np.exp(-t/(R*C)); q = C*U0*(1 - np.exp(-t/(R*C)))
W_src = np.sum(U0*I)*dt; W_R = np.sum(I**2*R)*dt; W_C = q[-1]**2/(2*C)
print(f"Manba: {W_src*1e3:.3f} mJ, rezistor: {W_R*1e3:.3f} mJ, kondensator: {W_C*1e3:.3f} mJ")
